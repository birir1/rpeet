# KCK — Kenya Community in Korea

Community management platform for Kenyans living in South Korea.

## Structure

- **backend/** — Django REST API (Python)
- **frontend/** — Laravel web application (PHP)
- **deploy/** — Docker, Nginx, CI/CD configuration

## Setup

See [backend/README.md](backend/README.md) for API documentation and setup instructions.

## Deployment

Any push to `main` triggers automatic deployment via GitHub Actions.
